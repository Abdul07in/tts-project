cURL Examples

Play in terminal

curl -s -X POST https://tts-project-s5s5.onrender.com/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"Hello world!","model":"aura-2-arcas-en"}' \
  | ffplay -i pipe:0 -autoexit -nodisp 2>/dev/null

Save to WAV file

curl -s -X POST https://tts-project-s5s5.onrender.com/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"Your appointment is confirmed for Monday at 3 PM.","model":"aura-2-luna-en"}' \
  -o output.wav
